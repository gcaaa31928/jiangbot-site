Privacy Policy

jiangbot · Effective 2026-10-16 · 隱私權政策（中文摘要在每節下方）

jiangbot is a personal, non-commercial project run by an individual developer ("we"). This policy explains what data jiangbot accesses through the Threads API, how it is used, and how to have it deleted.

1. Data we access

From the Threads keyword search (threads_keyword_search)

For public Threads posts that match our single keyword (「蔣萬安」), we receive: the post ID, text, media type, image URLs, permalink, publish time, the author's public username, and whether the post is a reply.

From the operator's own Threads account (threads_basic)

The only account that signs in to jiangbot is the operator's own. We store its access token so the daily search can run. We do not collect data from any other user's account, and no other person signs in.

我們只透過關鍵字搜尋讀取符合「蔣萬安」的公開貼文（貼文 ID、內文、圖片網址、連結、時間、作者公開帳號名稱）。唯一登入的帳號是作者本人，用來執行每天的搜尋。

2. How we use it

  • Humor rating. Each new post's text and images are sent to Anthropic's Claude API, which returns a humor score and a one-line explanation. Anthropic processes this data as our service provider under its Commercial Terms and Privacy Policy.
  • Sharing with a private group. For at most three posts per day, we send the author's username, the first 80 characters of the post, the one-line explanation, the first image (displayed directly from the Threads CDN, not re-uploaded), and a link to the original post to one private LINE group of about six friends, using the LINE Messaging API.
  • Avoiding duplicates. We keep a record of which posts we have already rated or shared.

We do not sell data, show ads, build profiles of people, contact post authors, or use the data for any other purpose. We do not post, reply, or like anything on Threads.

貼文文字與圖片會送到 Anthropic 的 Claude API 評估好不好笑；每天最多三篇的作者帳號名稱、前 80 字、笑點說明、圖片（直接引用 Threads 原網址）與原文連結，會分享到一個約六人的私人 LINE 群組。我們不販售資料、不投放廣告、不建立個人檔案，也不在 Threads 上發文或互動。

3. Storage and retention

  • Post data is stored in a local database on the operator's private home server. It is not uploaded to any other storage service.
  • Images are downloaded only in memory to send to the Claude API. They are never saved.
  • Stored post data is deleted automatically 30 days after the post's publish time.
  • Application logs are kept for 14 days.
  • The operator's Threads access token is stored on the same server and deleted when access is revoked.

資料只存在作者家中伺服器的本機資料庫；圖片不存檔；貼文資料在發文 30 天後自動刪除；log 保留 14 天。

4. Your choices and deletion

If you wrote a post that jiangbot processed and want its data removed, email me@redhuang.dev with the post link or your username. We will delete it within 7 days. See Data Deletion Instructions for details.

如果你的貼文被 jiangbot 處理過、想要刪除相關資料，請寄信到上方信箱，附上貼文連結或帳號名稱，我們會在 7 天內刪除。

5. Security

Secrets and the database live on a private server that is not exposed to the internet. Access is limited to the operator.

6. Children

jiangbot is not directed at children and does not knowingly process data about children beyond what appears in public posts that match the keyword.

7. Changes

We will update this page and its effective date if anything changes.
